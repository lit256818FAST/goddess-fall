## 六、资产验收门槛

- 2D：WebP 单张目标 60–120KB；透明立绘源文件必须是真 Alpha，不接受棋盘格或抠图白边。
- 立绘状态构建：`npm run build:dialogue-states`；生成脚本使用现有 RGBA 源图制作攻击/受击态，并再次检查 WebP Alpha。
- 3D：角色与 Boss 必须有 manifest、fallback、朝向、脚底原点、动作名和挂点。
- 环境：必须标注 footprint、是否阻挡、是否可互动、章节色板和 emissive 白名单。
- 运行时：图片路径无 404；桌面 1440×1024、移动 390×844 不遮挡关键操作。
- 发布：新增美术必须通过 `npm run build`，并重新检查 `dist` 体积；当前 `dist` 约 92.08 MiB，低于 100 MiB 上限；初始 `public` 包约 39.18 MiB，20 MiB 预算仍需处理。
