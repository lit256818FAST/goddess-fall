# 《女神之殇：无旗者》产品对标与局外长周期核心循环

> 文档性质：系统策划提案，不涉及代码修改  
> 适用版本：HTML / Vite / TypeScript / Three.js，小团队，完整资源包不超过 100MB  
> 原始依据：`work/story-source.docx`、现有 `README.md`、`docs/narrative.md` 与当前 3 人制 8×8 战斗规则

## 一、总监决策摘要

本项目不应做成“连续打关卡的微型战棋”，也不应真的模拟一套足球联赛。正确方向是借用足球经理游戏的周期节奏：**主页、战斗路线、阵容、战前准备、战后报告、成长共同构成长周期。**

建议产品定义：

> 一款以“无旗者使团”为核心的轻量叙事经营战棋。玩家每周安排三人出勤、处理一项局外事务，再进入一次 8—12 分钟的短战斗或非战斗事件；胜负都会推进故事，但会改变资源、人物关系、派系态度与下一场局势。

范围基线：

- 单次完整游玩：5—7 小时。
- 单次会话：15—20 分钟。
- 三章、十二个行动节点，其中七场正式战斗。
- 初始 3 人，首版最多 6 名可用角色，固定 3 人上阵。
- 只做 4 类长期资源，不做多货币经济。
- 首次加载目标不超过 8MB，完整下载目标 70—80MB，100MB 是不可突破的上限。
- 叙事与局外管理约占 55%，战斗约占 35%，结算约占 10%。

最重要的取舍是：**行动路线借鉴足球经理游戏的信息组织，但事件始终是战争、调查、护送与谈判，不把世界观改造成体育竞赛。**我们借的是节奏、阵容管理和对手准备，不是足球题材本身。

## 二、产品支柱

1. **准备比数值碾压重要**：提前知道目标、敌方意图和地形后，玩家通过选人、证据与行动计划获得优势。
2. **三人阵容有明确身份**：每个角色同时拥有战斗职业、派系背景和个人立场，换人不仅换技能，也会改变事件答案。
3. **失败不是读档点**：战败会损失资源、改变下场条件或令对手获得政治优势，但故事继续。
4. **招募是建立信任，不是抽卡消费**：候选人来自故事、调查与派系关系；如果加入随机性，只做公开、去重、仅用游戏内所得的三选一选秀。
5. **内容少而可复用**：少量棋盘通过目标、地形修正、敌方意图与政治后果形成差异，不依赖大量模型和动画。

## 四、长周期核心循环

### 4.1 一“周”的标准流程

这里的“周”只是叙事行动单位，不对应现实时间，不做每日登录。

1. **回到驻地**：读取战报、伤势、派系态度与新来信。
2. **查看战斗路线**：玩家知道未来三个节点的主要目标、风险等级和已掌握情报。
3. **安排三人阵容**：从最多 6 人中选 3 人，明确前卫、支援、机动职责。
4. **执行一项局外行动**：调查、休整、交涉、训练或招募，只能选一项。
5. **战前准备**：阅读敌方已知意图、地形、胜负后果；允许使用 1 份证据改变开局条件。
6. **开战或行动**：进入 8×8 战斗；调查、谈判等节点则进入对应的非战斗事件。
7. **战后报告**：战果、伤势、派系关系、人物对话与下一场变化同时出现。
8. **推进行动路线**：无论胜败都进入下一周；重大失败开启补救事件，不弹出 Game Over。

推荐节奏：局外 3—6 分钟，战斗 8—12 分钟，结算 2—3 分钟。

### 4.2 局外行动

每周只做一个，避免经营层膨胀：

- **调查**：提升对手情报，显示一个额外敌方意图或 Boss 机制。
- **休整**：清除最多两名角色的疲劳/伤势。
- **交涉**：改变一个派系的态度，或降低失败后的政治损失。
- **训练**：让一名角色在下一场获得一次性战术能力，不是永久刷属性。
- **招募**：推进候选人的信任条件，或开启一次三选一邀请。

不允许同时安排建筑、科研、制造、派遣队与交易所。这些都属于范围爆炸。

### 4.3 四类长期资源

| 资源 | 用途 | 上限与防膨胀 |
|---|---|---|
| 口粮 | 旅行、战后恢复、某些绕路选择 | 上限 9；通常每场收支 1—2 |
| 证据 | 揭示敌方机制、改变叙事判定、和平解决部分目标 | 上限 6；重要证据是命名物，不做碎片合成 |
| 派系态度 | 每个主要派系分别为敌对/警惕/中立/信任 | 不换算成通用货币，不存在一条“善恶值” |
| 队伍凝聚 | 解锁组合对话、降低失败损失 | 0—5；通过共同出战与诚实选择变化 |

疲劳和伤势是人物状态，不是资源。不得新增金币、钻石、体力、招募券、装备粉尘等平行经济。

## 五、首页信息架构

首页必须在五秒内回答四个问题：**下一步做什么、为什么做、谁能上、战前还能做什么。**

### 5.1 桌面版

```text
┌ 章节/第几周 ─ 下一节点倒计时（叙事） ─ 口粮/证据 ─ 保存 ┐
├──────────────┬───────────────────────┬──────────────┤
│ 战斗路线        │ 下一战：圣火审判庭          │ 三人阵容      │
│ · 本周          │ 目标 / 风险 / 已知意图       │ 角色状态      │
│ · 下周          │ 胜利与失败的可见后果         │ 替补与缺阵    │
│ · 下下周        │ [进入战前准备] 主按钮        │ [调整阵容]    │
├──────────────┴───────────────────────┴──────────────┤
│ 来信与局外行动：调查 / 休整 / 交涉 / 训练 / 招募（三张以内） │
└───────────────────────────────────────────────────┘
```

设计规则：

- 中央“下一场”永远是最大卡片，不能让玩家先翻菜单寻找主线。
- 只展示未来三个节点；完整路线进入“战斗路线”页。
- 出战区直接显示 3 人与异常状态，换人不超过两次点击。
- 来信最多 3 条，一周处理 1 条；未选事件按其自身逻辑结算，不积成任务垃圾。
- 不在首页摆巨大 3D 城镇、转盘、签到、商店、活动横幅。

### 5.2 移动端

底部固定五栏：`主页 / 阵容 / 战斗路线 / 档案 / 成长`。主按钮“进入战前准备”固定在主页底部安全区；资源折叠为一行；出战成员和来信纵向排列。战斗仍建议横屏，但局外管理必须支持竖屏。

## 六、职业与角色差异

### 6.1 六个职业原型

| 职业 | 战斗职责 | 局外价值 | 设计边界 |
|---|---|---|---|
| 守卫 | 护卫相邻友军、承受生命伤害、封锁通道 | 护送与威慑 | 不做无限嘲讽或纯血牛 |
| 调停者 | 恢复信念、削减狂热、令敌人停手一回合 | 宗教交涉、安抚群众 | 不兼任全能治疗 |
| 工程师 | 布置一次性障碍、拆装置、修改地形 | 设备调查、开辟路线 | 每场最多 1 个装置，避免建造系统 |
| 斥候 | 高机动、揭露伏兵、完成撤离/占点 | 提升对手情报 | 伤害较低，不能成为万能刺客 |
| 见证人 | 使用证据削弱敌方信念、记录战场事实 | 提高证据收益、开启真相选项 | 依赖准备，正面对抗弱 |
| 使节 | 交换友军位置、短暂停火、降低敌意 | 派系关系与招募 | 控制能力有次数限制，不可永久锁敌 |

首版虽定义六种原型，但每种只对应一名具名角色，不生产同职业普通兵。

### 6.2 首版六人名单

| 人物定位 | 推荐职业 | 独特钩子 |
|---|---|---|
| 主角“无旗者” | 使节/见证人二选一倾向 | 战前使用证据，战后决定公开、封存或交换 |
| 塞拉菲娜 | 调停者 | 保住信念濒危的友军；她在女神国事件中更有说服力，也更容易被质疑 |
| 蕾娜 | 工程师 | 拆除、架设掩体、识别理性派装置；与神迹解释持续冲突 |
| 边境老兵 | 守卫 | 可替他人承担一次致命生命伤害；厌恶无意义牺牲 |
| 河湾向导 | 斥候 | 首回合揭示一项敌方意图；擅长护粮与撤离 |
| 流亡抄写员 | 见证人 | 胜利时多保留一份证据，失败时减少档案损失 |

角色差异由四层组成：`职业原型 + 派系背景 + 一个个人特性 + 一条关系冲突`。不使用稀有度星级、元素克制、随机词条。

### 6.3 轮换与成长

- 出战后可能获得“疲劳”；再连续出战则变为“轻伤”。休息一周清除，不设现实时间等待。
- 每人一章末获得一次二选一专精，整个首周目最多两次成长。
- 每人只装备一件“信物”，全队共享的信物不超过 8 件，无颜色品质和强化等级。
- 两名角色共同完成关键事件会形成一个关系标签。标签最多两条，只改变一个动作或一个对话，不做复杂化学反应数值。

## 七、章节行动路线

首版采用“三章十二节点、七场战斗”。玩家统一在“战斗路线”页查看节点；具体节点分别是案件、护送、封锁、会谈或决战。

### 序章：圣火案教学（30—45 分钟）

- 调查守火人或祭坛。
- 三人制教学战。
- 公开真相 / 维持秩序 / 失败继续三种结算。
- 解锁主页与第一段完整行动路线。

### 第一章：灰烬圣路（4 节点，2 战斗）

| 周次 | 类型 | 内容与产出 |
|---|---|---|
| 1 | 调查 | 复盘圣火案，选择调查或休整；认识边境老兵 |
| 2 | 谈判 | 女神国检查站，可用证据通行或接受附加条件 |
| 3 | 正式战 | 护送证人穿过圣辉骑士封锁，目标是撤离而非全歼 |
| 4 | 章 Boss | 审判官奥德里克：保护祭坛、击溃信念或活捉三种解法 |

### 第二章：铁砧与粮路（4 节点，3 战斗）

| 周次 | 类型 | 内容与产出 |
|---|---|---|
| 1 | 招募 | 蕾娜引荐工程师路线；在休整与提前侦察之间选择 |
| 2 | 正式战 | 拆除封路机械，战斗目标由击杀改为占据三个装置格 |
| 3 | 危机战 | 河湾粮队遭袭；保粮、救人不能同时满额完成 |
| 4 | 章 Boss | 铁砧指挥官与移动壁垒，需先通过情报找到弱点 |

### 第三章：无旗归途（4 节点，2 战斗）

| 周次 | 类型 | 内容与产出 |
|---|---|---|
| 1 | 派系会议 | 一月王国、黑教会、新卡瓦拉提出相互冲突的条件 |
| 2 | 选秀/招募 | 三名已解锁候选人中选择一人；未选者以后仍可能出现 |
| 3 | 正式战 | 夜路突围，视野与意图信息受限；可通过证据恢复信息 |
| 4 | 幕终 Boss | 不是“神本人”，而是代表一种答案的执旗者；战后决定建立新旗、拒绝所有旗或暂时联盟 |

行动路线不模拟其他十二个派系之间的自动联赛，也不生成虚假积分榜。章节进度只用 0—3 枚“行动印记”表示准备度：完成次要目标或妥善处理失败可获得印记，印记改变 Boss 开局条件，而不是阻止玩家进入结局。

## 八、Boss 梯度

Boss 不靠翻倍血量区分，靠规则压力升级。

| 层级 | 作用 | 机制 | 首版示例 |
|---|---|---|---|
| Tier 1：队长 | 检验一个基础概念 | 单一鲜明机制，情报可完全揭示 | 奥德里克的信念护盾；玩家选择打生命、打信念或保全目标 |
| Tier 2：派系指挥官 | 检验阵容与战前准备 | 两阶段目标、一次增援、地形装置 | 铁砧移动壁垒；未调查弱点也能赢，但代价更高 |
| Tier 3：理念执旗者 | 检验战斗与政治取舍 | 战中改变胜利条件，证据决定第三种解法 | 季终执旗者：击败、说服、共同对敌对应三种结算 |

每个 Boss 只由三个变量构成：`一个核心机制 + 一个战场修正 + 一个政治后果`。禁止叠加免疫表、随机阶段、召唤物海、专属装备农场。

战败处理：

- Tier 1：失去 1 口粮或一名角色疲劳，继续行动路线。
- Tier 2：敌方在下一节点获得一个公开优势，玩家出现补救事件。
- Tier 3：仍进入结局，但对手掌握叙事主动权；可在通关后解锁一次非强制重赛。

## 九、招募与“抽取”方案

### 9.1 MVP：确定性招募

首版不做真正抽卡。候选人由剧情条件解锁：完成其委托、达到派系态度、持有对应证据。每章至多招募一人，队伍上限 6 人。这样能保证写作量、战斗平衡和模型量都可控。

流程：

1. 在行动路线中结识候选人。
2. 人物卡公开职业、个人冲突和加入条件。
3. 完成条件后发送邀请。
4. 若同章有两名候选人，选择其一；未选者不会消失，可在后续来信中再次出现。

### 9.2 P1：公开的“三选一旅人名册”

如果必须加入“抽取的惊喜”，采用无付费的洗牌袋选秀：

- 每完成两场正式节点获得一次“会面”，不是购买招募券。
- 从已解锁的小池中公开展示 3 人，选择 1 人加入或选择保留名额。
- 抽到的人从池中移除，重复角色不可能出现。
- 概率和剩余候选人全部公开；不设限定池、保底、十连、重复转化。
- 角色强度横向，不设 SSR；稀有只代表剧情出现条件，不代表数值碾压。
- 不可使用真钱、广告观看或现实时间加速。

推荐商业方式是买断制或免费序章 + 一次性解锁完整版；未来可售原声、设定集或纯外观支持包。禁止角色数值付费。

## 十、局外状态与现有战斗的接口要求

系统层只需向现有战斗传入少量可解释数据：

- 三名出战成员及其职业能力。
- 每人最多一个状态：正常、疲劳或轻伤。
- 对手情报等级 0—2，决定显示多少敌方意图。
- 一份可选证据，改变一个开局单位、地形或胜利条件。
- Boss 修正与本场次要目标。

战斗向局外返回：胜负、次要目标、角色受伤、消耗证据、关键敌人状态。不要把口粮、派系态度等直接塞进战斗 HUD。

概念状态机：

```text
主页 → 战斗路线 → 阵容/局外行动 → 战前准备 → 剧情 → 开战或谈判 → 战后报告 → 成长 → 主页
```

技术上建议保留当前纯状态思路，新增一个小型 `CampaignState`：章节、周次、行动路线、名单、出战阵容、四类资源、派系态度、状态、招募池和故事标记。以本地存档为主，不做账号、服务器、云同步。GitHub 上 `boardgame.io` 的阶段与动作日志可作为设计参照，但首版没有必要安装它。

## 十一、100MB 预算与 Web 可行性

建议把“100MB 以内”变成双指标：**首次可玩下载 ≤8MB，完整缓存 ≤80MB**，预留 20MB 防止后期失控。

| 分类 | 完整版目标 |
|---|---:|
| JS/CSS/数据/存档代码 | 2MB |
| 公共战场、特效、共享材质 | 14MB |
| 六名角色模块化 GLB | 14MB |
| 敌方与三名 Boss 模块化 GLB | 12MB |
| UI、立绘、章节插图 | 14MB |
| 音乐与音效 | 18MB |
| 中文字体子集 | 2MB |
| 三章独有场景增量 | 4MB |
| **合计目标** | **80MB** |

执行原则：

- 角色共用骨骼与基础动作，职业差异靠武器、披风、头饰和配色。
- GLB 使用 Meshopt/Draco，纹理使用 KTX2/WebP；单角色不做独立 4K 纹理。
- 音乐按章懒加载，语音只保留少量短句，不做全配音。
- 棋盘复用几何体，通过灯光、标记、雾、装置和目标改变体验。
- 首页是 HTML/CSS，不做 3D 可行走驻地。
- 每章首次进入再下载本章资源，离线缓存已下载内容。

## 十二、优先级与明确裁剪

### P0：MVP 必须做

- 主页与战斗路线中的未来三节点。
- 三人出战、最多六人名单、疲劳/轻伤轮换。
- 四类长期资源与每周一次局外行动。
- 三章十二节点的骨架，其中七场战斗。
- 六个职业原型的最小能力版本。
- 确定性故事招募，不做抽卡。
- 三层 Boss 各一个，失败继续。
- 本地自动存档、章节资源懒加载。
- 新手教程覆盖“主页—战斗路线—阵容—战前准备—开战—战后报告—成长”的完整一周，而非只教战斗。

### P1：首版稳定后再做

- 无付费、无重复的三选一旅人名册。
- 两条角色关系标签与组合对话。
- 非强制重赛、章节路线回顾、档案馆。
- 一场可通过充分准备而自动解决的低风险节点。
- Boss 情报等级的更多视觉反馈。

### P2：有真实玩家数据后再决定

- New Game+ 挑战行动路线。
- 纯外观角色变体。
- 共享行动路线种子或排行榜式挑战，但仍不做实时 PvP。
- 更多派系章节与角色扩展包。

### 明确不做

- 在线 PvP、实时合作、公会、聊天、周期性运营服务器。
- 每日任务、签到、现实时间体力、限时卡池。
- 付费抽卡、角色碎片、重复角色、十连、装备卡池。
- 转会市场、合同谈判、经纪人、工资和完整足球联赛模拟。
- 基地建设、科研树、制造、装备强化、随机词条、颜色品质。
- 开放世界、可行走 3D 主城、程序化无限战役。
- 首版覆盖全部十二派系、20+ 可玩角色、全语音、大量过场动画。
- 永久死亡、数周住院、不可逆角色废弃。
- 任何要求后端常驻、账号体系或持续运营团队的功能。

## 十三、验收指标

玩法原型通过的最低标准：

- 80% 测试者进入首页后 10 秒内能指出下一场目标和可操作按钮。
- 完成序章后，玩家能解释“为何要换人”，而不只说“谁攻击高”。
- 单场战斗中位时长 8—12 分钟，完整一周 15—20 分钟。
- 首章至少 70% 玩家主动使用一次调查/休整，并能感知它改变了战斗或结算。
- 战败玩家中至少 70% 选择继续推进，而非立即读档。
- 六名角色没有一名在所有目标中都是最优解。
- 首次加载 ≤8MB，完整缓存 ≤80MB，低配集显设备保持可操作帧率。

## 十四、最终建议

下一阶段不要立刻扩大战斗内容，而应先做一个“完整周”纵切：主页 → 查看战斗路线 → 三人排阵 → 选择调查、休整或交涉 → 战前准备 → 圣火案开战 → 战后报告与成长 → 下一周变化。只有这条循环被试玩证明有吸引力，再制作后续两章与招募。

最小成功版本不是“有很多关卡”，而是玩家打完一场后自然产生三个念头：**下一场是谁、我该换谁、这周先调查还是先救人。**只要这三个问题成立，战斗就真正成为长周期的一部分。
