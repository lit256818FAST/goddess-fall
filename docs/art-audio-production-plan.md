# 《女神之殇：无旗者》美术与音频生产计划

版本：垂直切片 v1  
范围：网页端 2D 叙事 + 固定斜视角低多边形战场  
硬约束：完整下载小于 100 MB；首屏目标小于 8 MB；无 CDN 运行依赖。本计划只规定生产方向，不立即生成图片。

## 一、制作总纲

视觉定位：

> 冷灰石城中的残火圣金。低多边形战棋像被摆上祭坛的历史沙盘；人物像从受潮的宗教档案与战争公报中走出来。

资源优先级：信息可读性 > 角色辨识度 > 氛围 > 细节数量。每张新图必须对应明确界面或剧情节点，不生产没有用途的库存图。

## 二、风格圣经

### 1. 核心关键词

- 宗教政治悬疑、冷石、旧铜、灰烬、圣金。
- 克制的中低魔，手工档案感，低模祭坛沙盘。
- 悲悯而非猎奇，威严而非华丽。
- 禁止：日系萌系、写实照片感、血浆猎奇、赛博霓虹、塑料材质、通用手游金光、所有角色同一张 AI 美人脸。

### 3. 2D 插画语言

- 半写实手绘概念画，形体概括，带轻微干刷与版画颗粒。
- 冷环境光 + 单一暖光源；人物脸部保留眼窝、鼻梁和嘴角。
- 主体放在中央 70% 安全区，左右预留 UI 与手机裁切空间。
- 材质为旧铜、磨损钢、粗织罩袍、灰石、油烟。
- 每张图只保留一个叙事焦点；文字和 UI 一律由网页叠加。
- 暴力用烟、烧痕、破损和姿态表现，不靠大面积血液。

### 4. 人物统一规范

采用胸像主立绘一源多用：

- 制作母版：1536×2048 透明 PNG，不进入游戏。
- 游戏主图：768×1024 WebP。
- 卡面：384×512 WebP，由主图裁切。
- 对话头像：256×256 WebP，由主图裁切并人工校正眼位。
- 每人首批只做中性、怀疑/恐惧、决意/愤怒三种状态。
- 情绪优先局部编辑，不重新随机生成整个人物。

| 角色 | 固定辨识锚点 |
|---|---|
| 无旗者 | 旧旅行斗篷、无徽银灰扣、证据匣、克制中性轮廓 |
| 塞拉菲娜 | 象牙白罩袍、断裂日轮胸针、暖金面光 |
| 蕾娜 | 钢蓝短披肩、工程工具带、护目镜或测量器 |
| 老玛拉 | 弯背、油灯钥匙串、烟熏手与旧围巾 |
| 灰眼破坏者 | 灰布蒙面、改造祭司袍、油罐与灰眼符号 |

### 5. 3D 战场语言

- 保留现有程序化低多边形方向，不追求近距离面部表演。
- 单位共享 1—2 套骨架与动作，用头盔、肩甲、罩袍、盾徽、武器和阵营色换装。
- 单角色 5k—10k 三角面，固定斜视角优先保证轮廓。
- 玩家与敌方除青/红外，用圆/六边底座和方/切角底座区分。
- 一张战场只设一个暖光焦点，环境底光保证棋盘与单位可读。
- 重复地砖、柱、火盆实例化；换色走材质参数。

### 6. UI 语言

- 细金线框、轻磨损，不用厚重边框。
- 图标为锐角线性风格，1.5—2 px 视觉线宽。
- 卡面不做白蓝紫金稀有度，改用证据可靠度、关系和伤势语义。
- 常规动效 180—260 ms；章节转场 600—900 ms；支持减少动画偏好。

## 三、统一局外循环包装

借鉴的是信息组织与仪式感，不是体育玩法：

1. **主页**：呈现无旗使团案头。中央为当前案件主卡，左侧队伍状态，右侧下一事件和关系风险，底部进入战斗路线地图。
2. **角色档案卡**：显示生命、信念、伤势、阵营、关系警告和核心能力，不显示单一综合战力。
3. **阵容**：三个出战槽、轮换成员、组合关系与任务适配；相斥角色显示队内矛盾，共同经历后解锁暂时共识。
4. **营地**：战后谈话、治疗、证据配置、关系变化。只用一个营地母图与点击热点，不做自由走动。
5. **战斗路线地图**：调查、谈判、战斗、营地、决断五类节点；显示已完成结果、下一站和不可逆风险。
6. **战后报告**：展示任务结果、平民安全、生命/信念、证据、阵营关系和下一站，而非只显示胜负。

## 六、格式与导出

- AVIF：少量大背景、章节封面、结局图；质量 45—55。
- WebP：人物透明图、地点、事件、证据与 fallback；质量 68—82。
- PNG：只作母档或极小无损资产，不打包大 PNG。
- SVG：Logo、徽记、状态图标；入库前清理路径和 metadata。
- OGG Opus/Vorbis：正式音乐音效。WAV/FLAC 只归档。
- 不打包 4K 图；桌面背景最高 1920×1080，常规地点 1600×900，事件 960×540，证据 512×512，图集最大 1024×1024。

## 七、复用与懒加载

### 1. 复用

- 人物母版复用到头像、卡面、阵容、营地、结算。
- 地点母图复用到对话背景、章节卡、行程缩略图、加载图。
- 阵营徽记复用到卡面、地图、底座、关系面板。
- 证据图复用到调查奖励、装备槽、档案馆、战前干预。
- 3D 人物共享骨架、动作和材质模板。

### 2. 分包

| 包 | 内容 | 目标 |
|---|---|---:|
| Shell 首屏 | HTML/JS/CSS、字体子集、Logo、标题图、标题音频前段、基础图标 | ≤ 8 MB |
| Chapter 1A | 角色、LOC-01—04、调查音乐和主要音效 | ≤ 18 MB |
| Battle 1 | 战斗音轨、Boss 横幅、必要 FX | ≤ 8 MB |
| Chapter 1B | LOC-05—06、结局图、结局和营地音乐 | ≤ 12 MB |
| Optional cache | 高质量标题、非关键变体、档案扩展 | ≤ 10 MB |

加载顺序：

1. 首屏先加载标题图、Logo、字体和短音频；可交互后再预取主页。
2. 阅读 opening 时预取调查共用资源。
3. 选路线后优先加载所选路线，另一条仅在空闲网络预取。
4. confrontation 时预取战斗音频与 Boss 卡；战斗中预取结算图。
5. 用哈希文件名和长期缓存；离开章节释放 GPU 纹理但保留磁盘缓存。
6. 大图先显示 20—40 KB 模糊占位。

## 九、AI 美术生产协议

先建参考包再批量生成。参考包包括色板、材质板、地点平面关系、人物多角度、服装拆解、徽记和两张批准的标杆图。

统一提示词固定段：

> restrained medieval political fantasy, hand-painted concept illustration with subtle woodcut grain, cold slate stone and worn bronze, desaturated palette, one controlled warm sacred light, readable silhouettes, compassionate historical drama, no modern objects, no typography, no glossy plastic, no neon, no anime, no photorealistic camera look

每张图入库前检查：

- 人物脸型、年龄、发型、服装和道具是否漂移。
- 地点门、祭坛、城墙和光源位置是否连续。
- UI 安全区与手机裁切是否通过。
- 是否有乱码、多指、重复武器、徽记穿模和无逻辑建筑。
- 缩到 320 px 后是否仍能识别主体。
- 与低模战场并排时是否属于同一色温和材质体系。
- 压缩后是否有透明边黑线、色带或脸部糊化。

只有风格、叙事、技术三项同时通过才入库。

## 十、版权与生成记录

建立 assets-manifest.csv/json，记录：

- asset_id、文件名、用途、章节、负责人。
- 来源类型、来源 URL、作者、下载日期、许可证版本。
- AI 工具、模型名称和版本、生成日期、seed、完整正负提示词。
- 参考图及权利来源、人工修改、导出设置、校验哈希。
- 是否要求署名、署名文本、许可证原文归档位置。

免费下载不等于可商用。外部模型只接受明确许可证；CC BY 按要求署名；来源不清或禁止再分发的素材不进入项目。母版、WAV、参考图和生成历史不进入游戏包。

## 十一、三批生成顺序

### 第一批：视觉锚点与首屏

1. LOGO-01。
2. HERO-01 三个构图草案，选一个精修。
3. 无旗者、塞拉菲娜、蕾娜的中性主立绘与参考板。
4. LOC-01 与 CH-01。
5. 六个核心 SVG 图标。
6. MUS-01 与六个 UI 核心音。

门槛：标题、主页和三张角色卡风格统一；手机/桌面裁切通过；首屏 ≤8 MB；先请用户确认再扩产。

### 第二批：完整章节与局外循环

1. 老玛拉、灰眼破坏者及五名角色的局部情绪变体。
2. LOC-02—04、LOC-06、EVT-01—03。
3. 三张证据图、剩余 UI 与阵营图标。
4. MAP-01 及阵容/营地卡面裁切。
5. MUS-02、03、09 与环境/剧情音效。
6. Boss 横幅与灰眼符号。

门槛：人物稳定、地点连续；主页、阵容、营地、战斗路线形成清晰的局外循环；累计下载 ≤55 MB。

### 第三批：战斗、结局与冻结

1. LOC-05、三张结局图、Boss 与信念 FX。
2. MUS-04—08 的基础层与危险层。
3. 战棋、角色短声、结局标志音效。
4. 必要时再制作共享骨架 GLB、换装和 KTX2，禁止扩为全 3D 剧情。
5. 全量压缩、重复扫描、manifest 和许可证归档。
6. 慢网、普通笔记本、手机、减少动画、色弱与低亮度实测。

冻结门槛：资源目标 ≤90 MB、绝不超过 100 MB；首屏 ≤8 MB；章节按需加载；角色、地点和战场无明显风格漂移；来源全部可追溯。

## 十二、当前制作决策

1. 先做标题图和三位核心人物，不同时开十几个角色。
2. 先批准一个圣辉广场母图，再衍生调查、战斗和结局状态。
3. 卡面、阵容、营地和结算使用同一主立绘，不生成卡牌专用人物。
4. 音乐先做标题、调查、战斗三条主题，确认语言后再做变奏。
5. 3D 承担空间与规则，2D 承担表情和戏剧高潮，不增加自由探索。
6. 每批结束进行包体、加载、视觉一致性和版权四项审计。
