# 《女神之殇：无旗者》玩家术语表

版本：Milestone A

本表约束产品定义、界面、教程、剧情文本与制作文档。对标研究在解释来源游戏时可以保留足球专有名词，但必须明确它属于参考对象，不能成为本作玩家界面用语。

## 核心流程

| 场景 | 统一用语 | 禁止用于玩家界面的旧称 | 使用示例 |
|---|---|---|---|
| 完整循环 | 主页—战斗路线—阵容—战前准备—开战—战后报告—成长 | 主页—赛程—阵容—赛前—比赛日—赛后—赛季 | “返回主页查看下一段战斗路线。” |
| 长线地图 | 战斗路线 | 赛程 | “打开战斗路线。” |
| 一次行动的分支与顺序 | 行动路线 | 赛程 | “失败将改变下一段行动路线。” |
| 进入战斗前 | 战前、战前准备、战前简报 | 赛前、赛前准备、赛前简报 | “在战前准备中投入一份证据。” |
| 战斗启动按钮 | 开战 | 比赛、比赛日、开始比赛 | “开战” |
| 战斗完成后 | 战后、战后报告、战报 | 赛后、赛后数据、赛后结算 | “战后报告已记录伤势。” |
| 大章节 | 第一幕、第二幕、第三幕 | 赛季、第一赛季 | “第一幕 · 灰烬圣路” |
| 单幕连续任务 | 第一战役、第二战役 | 赛季 | “第一战役共包含四个行动节点。” |
| 可出战人员 | 阵容、出战成员、轮换成员 | 球员、首发球员、替补球员 | “从阵容中选择三名出战成员。” |
| 时间单位 | 周、行动周 | 赛程周、比赛周 | “每个行动周选择一项局外行动。” |

## 信息层级

- “战斗路线”用于导航页名称，强调未来战斗与关键节点。
- “行动路线”用于节点顺序、分支后果和非战斗节点，覆盖调查、谈判、护送、休整与战斗。
- “战前准备”是可操作页面；“战前简报”是其中的敌情、地形与后果信息区。
- “战后报告”是完整结算页面；“战报”是其中的事件记录或返回主页后的摘要。
- “成长”包含人物状态恢复、关系变化、专精选择与证据链推进，不使用等级赛季或体育排名表达。

## 可保留例外

以下情况可以出现足球术语：

1. 对标表中的正式游戏名和该游戏真实功能，例如 Football Manager 的球员数据库、赛前简报与赛季模拟。
2. 解释设计来源时的明确引用，例如“参考足球经理游戏的周期组织方式”。
3. “不做事项”中描述被排除的体育系统，例如“不做足球联赛模拟”。

例外段落不得把本项目的节点称为赛程，不得把本项目战斗称为比赛或比赛日，也不得把第一幕称为赛季。

## 编写检查

- 按钮使用动词：`进入战前准备`、`调整阵容`、`开战`、`查看战后报告`、`继续行动路线`。
- 页面标题使用名词：`主页`、`战斗路线`、`阵容`、`战前准备`、`战后报告`、`成长`。
- 同一句话不混用“战斗路线”和“行动路线”：地图页用前者，后果与分支说明用后者。
- 文档和数据文件统一保存为 UTF-8；中文引号、破折号与省略号不得因转码变成乱码。
