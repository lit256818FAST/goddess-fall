# 《女神之殇：无旗者》总监方向与制作路线图

版本：第一幕立项规划  
阶段：方向冻结，尚未启动本轮功能开发

## 一、最终产品方向

本项目不再定义为“带几段剧情的短战棋”，而是：

> 一款以无旗者使团为核心的轻量叙事经营战棋。主页、战斗路线、阵容、调查、人物关系、招募和政治后果共同构成长周期。

从足球游戏借用的是周期组织方式，而不是足球题材。下表左栏只用于说明对标来源，右栏是本项目统一用语：

| 足球游戏结构 | 本项目对应结构 |
|---|---|
| 俱乐部主页 | 无旗使团案头主页 |
| 球员卡 | 角色档案卡 |
| 首发与替补 | 三人出战与三人轮换 |
| 赛程 | 调查、护送、谈判、战斗、Boss 构成的行动路线 |
| 球探与转会 | 剧情招募与旅人名册 |
| 赛前报告 | 战前简报：敌情、地形、证据与失败后果 |
| 比赛 | 开战：进入 8×8 战棋；谈判节点则进入关键交涉 |
| 赛后数据 | 战后报告：伤势、证据、关系、派系态度和下一场变化 |

玩家结束一场战斗后，必须自然产生三个问题：下一场是谁、我该换谁、这周先调查还是先救人。

## 二、第一幕范围

- 首通时长：4.5—5.8 小时。
- 三章、12 个行动节点、7 场战斗。
- 84 个剧情段落，16 次有效插画调用。
- 6 名具名角色，固定 3 人出战。
- 4 个核心势力：女神国、卫道士军国、新卡瓦拉、黑色教廷。
- 其他 8 个势力只通过传闻、来信和幕终钩子露面。
- 3 个阶梯 Boss：奥德里克、赫尔曼与移动壁垒、塞巴斯蒂安。
- 3 条证据链：圣火机关、边境利益、内心审查。
- 3 个幕终方向：公开档案、临时四方公约、无旗封存。
- 战败继续推进，改变后续条件，不把失败统一做成读档点。

第一幕不回答女神是否真实存在，只回答更具体、可被证据支持的问题，保留作者设定的模糊性。

## 三、长周期核心循环

每个行动周包含：

1. 返回驻地，读取战报、伤势、人物来信和派系变化。
2. 查看战斗路线中的未来三个节点及下一场已知风险。
3. 从 6 人名单中安排 3 人出战。
4. 在调查、休整、交涉、训练、招募中选择一项局外行动。
5. 查看战前简报，并选择是否投入一份证据改变开局。
6. 进入 8—12 分钟战斗，或完成调查/谈判节点。
7. 查看战后报告、人物对话和不可逆后果。
8. 推进下一段行动路线；胜败都继续。

长期系统只保留口粮、证据、派系态度、队伍凝聚四类资源。疲劳和轻伤是角色状态，不新增金币、钻石、体力、碎片与装备粉尘。

## 四、职业与角色差异

首版使用六个功能明确的职业，不制造同职业普通兵：

| 职业 | 战斗功能 | 剧情/局外功能 |
|---|---|---|
| 守卫 | 护卫、封路、代受生命伤害 | 护送与威慑 |
| 调停者 | 恢复信念、削减狂热、短暂停手 | 宗教交涉与安抚群众 |
| 工程师 | 拆装置、临时障碍、改地形 | 识别机关和开辟路线 |
| 斥候 | 高机动、揭伏兵、撤离占点 | 提升敌情等级 |
| 见证人 | 用证据削减信念、记录战场事实 | 增加证据收益和真相选项 |
| 使节 | 换位、停火、降低敌意 | 派系关系和招募 |

每个角色由“职业 + 派系背景 + 个人特性 + 一条关系冲突”构成。无稀有度星级、元素克制、随机词条和综合战力数字。

## 五、招募与抽取决策

MVP 采用确定性剧情招募：认识候选人、公开加入条件、完成委托或派系条件、发送邀请。

如果测试证明玩家需要抽取惊喜，P1 才加入“旅人名册”：

- 从已解锁候选人中公开三选一。
- 候选人选中后从池中移除，不会重复。
- 剩余池与概率全部公开。
- 只由游戏进度获得，不可付费。
- 不做 SSR、限定、十连、保底、重复转化和数值售卖。

传统随机卡池会稀释具名角色的叙事价值，并把内容、平衡和美术产能迅速放大，因此不进入首版。

## 六、美术与音频方向

视觉定位：冷灰石城中的残火圣金；半写实手绘概念画带轻微版画颗粒，与现有低多边形战场共享色温和材质语言。

2D 承担人物表演与戏剧高潮，3D 承担空间、规则和战术信息。第一批不做全 3D 剧情和可行走主城。

首批美术部门只生产六类锚点：

1. 标题主视觉：圣辉城、熄灭圣火、无旗者背影。
2. 无旗使团案头主页。
3. 无旗者、塞拉菲娜、蕾娜三张角色母版立绘。
4. 圣辉广场地点母图与第一章封面。
5. 大陆战斗路线地图。
6. 核心图标、标题音乐、调查音乐、战斗音乐和基础反馈音效。

角色母版一源多用，裁切为对话头像、阵容卡、营地卡和结算卡；地点母图派生时间、烟雾、群众和战后状态，避免为每句对白单独生成图片。

音频首版规划 9 首短主题/循环曲和约 60 项 UI、战斗、环境、剧情音效，不做全语音。音乐按章节懒加载。

## 七、包体与加载红线

- 首次可玩下载不超过 8MB。
- 完整缓存目标 80—90MB。
- 100MB 为不可突破硬上限。
- 大图使用 AVIF/WebP，透明人物使用 WebP，图标使用 SVG，音频使用 OGG。
- 不打包 4K 图片；桌面背景最高 1920×1080。
- 角色共享骨骼与动作，职业差异优先靠武器、肩甲、披风、徽记和配色。
- 建立资产 manifest，记录来源、许可证、AI 模型版本、提示词、seed、人工修改和导出参数。

## 八、制作阶段与门禁

### 里程碑 A：完整一周纵切

交付：标题页、案头主页、未来三节点、三人排阵、调查/休整/交涉三选一、现有圣火战、战后报告、下一周与下一行动变化；加入首批标题图、三人立绘和三条核心音乐。玩家流程统一为“主页—战斗路线—阵容—战前准备—开战—战后报告—成长”。

门禁：玩家 10 秒内知道下一场目标；能完成“驻地→准备→剧情→战斗→结算→驻地”闭环；首屏小于 8MB。

### 里程碑 B：第一章与 Tier 1 Boss

交付：圣火案四节点、完整证据链、奥德里克三种解法、两个营地事件、第一次职业倾向。

门禁：剧情阅读达到 75—95 分钟；战斗结果真实改变政治结算；Boss 不靠单纯加血。

### 里程碑 C：第二章与阵容轮换

交付：铁砧与粮路四节点、科尔加入、疲劳/轻伤、三座封路机、粮车危机、移动壁垒 Boss。

门禁：测试者能解释为什么换人；六人中没有角色在所有目标中都是最优解。

### 里程碑 D：第三章与幕终

交付：黑色教廷四节点、阿格尼丝、雾中意图限制、六人围桌、塞巴斯蒂安终战与三个结局。

门禁：完整首通 4—6 小时；失败路线也能进入合理结局；三个结局均不写死女神真相。

### 里程碑 E：资源冻结与发布候选版

交付：全部插画和音频压缩、版权清单、存档迁移、移动端与低配设备验收、色弱与减少动画模式。

门禁：完整缓存不超过 90MB、控制台无严重错误、核心流程自动测试与真实浏览器冒烟测试通过。

## 九、明确暂缓

- 在线 PvP、实时合作、公会、聊天和周期性运营服务器。
- 每日任务、签到、现实时间体力和任何付费抽卡。
- 开放世界、自由移动 3D 主城、基地建造、科研树。
- 装备强化、随机词条、颜色品质和角色碎片。
- 首版覆盖全部十二势力、20 名以上角色、全语音和大量过场动画。
- 程序化无限战役、真实足球联赛模拟、转会市场和合同系统。

## 十、下一项执行命令

方向确认后，不立即同时制作三章。项目组先只执行里程碑 A“完整一周纵切”，并由美术部门先给出标题主视觉、案头主页和三名角色母版的低清方案供总负责人确认。完整一周的玩家可见内容以 `src/content/campaignWeekOne.ts` 为准；只有主页循环和视觉语言通过试玩，再进入第一章扩写与 Boss 制作。
