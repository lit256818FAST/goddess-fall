战后页面现由 `lastReport` 的实际 delta 动态生成变化列表，不再渲染静态 `outcome.changes`：

- 胜利真实新增“折断的异制扳手”、证据 +1、平民安全 +1、凝聚 +1。

`campaign.test.ts` 已覆盖三项行动、胜败全部承诺状态与推进路线。P0 静态回归通过；真实页面显示仍列入浏览器阶段复核。

## P1 回归：同版本损坏存档可能导致首屏崩溃——已关闭

`loadCampaign()` 已改为完整白名单验证：页面、行动、角色 ID、角色状态、命名证物、风险枚举、阵容唯一性、资源范围、派系态度和 `lastReport` 均需合法；任何字段失败都回退 `createCampaignState()`。

新增测试以非法页面、非法角色 ID 和负数资源构造同版本坏存档，确认安全回退初始状态。P1 静态回归通过。

## 术语检查

对 `src/`、`index.html`、`README.md` 扫描以下旧词：`赛程`、`赛前`、`比赛日`、`比赛`、`赛后`、`赛季`、`球员`、`俱乐部`、`更衣室`。

结果：玩家运行时源码零命中。当前流程使用“主页—战斗—阵容—战前准备—开战—战后报告—成长”，路线页与地图可访问文本使用“战斗路线/行动路线”。
