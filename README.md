# 女神之殇：无旗者（网页原型）

轻量叙事经营战棋：HTML/CSS 承载七卷《铁与火》主线与“无旗使团”支线，Three.js 负责固定斜视角 8×8 战场、章节换色地形、GLB 角色与 Boss 动画。

## 启动

```bash
npm install
npm run dev
```

生产构建：`npm run build`，产物位于 `dist/`。

## 操作

从启动页选择主线或支线。战斗中先点击我方单位查看移动范围和敌方意图，再移动、生命攻击、信念攻击或使用职业技能；敌人在我方结束阶段后统一行动。亚瑟主线还包含技能树、军职任务、永久装备和 Boss 机制目标。

## 资产与包体原则

- 首屏与章节资源分包；模型统一使用 GLB，优先共享骨架、章节懒加载与材质换色。
- 免费资产必须逐项登记作者、来源链接、许可证、修改记录。
- 固定视角、共享几何体、实例化地块与模块化换装。
- 构建不得依赖 CDN；部署时为哈希资源设置长期缓存。

`src/render/` 是渲染边界。剧情与规则可分别放入 `src/content/` 和 `src/game/`，通过纯数据接口接入。
